# LisaNateHogwarts01 — V3 开场测试版

这版完全保留 V2 已经确认过的 UI 框架，只改开场流程与玩家资料。

## 新开场流程

1. 显示用户提供的九月 / 九又四分之三站台 / 列车开场文字。
2. 文字结束后进入生日填写页。
3. 玩家填写生日（月 / 日）。
4. 进入姓名填写页，填写“名”和“姓”。
5. 后续剧情可以直接写 `【玩家名字】`，游戏会自动替换成玩家输入的姓名。
6. 正文中用 `*文字*` 包起来，可以显示斜体。
7. 进入原本的分院流程。

## 这版新增的正文写法

### 自动插入玩家姓名

直接写：

```js
"十五岁的【玩家名字】，你好。"
```

玩家如果填写 Jane Doe，游戏里就会显示：

```text
十五岁的 Jane Doe，你好。
```

### 斜体

直接写：

```js
"也许会有*期待中的邂逅*。"
```

星号里的部分会自动显示为斜体。

## 玩家资料

角色状态面板现在会记录并显示：

- 姓名
- 生日
- 学院
- 血统背景
- Lisa 好感度
- Nate 好感度

生日目前只填写“月 / 日”，因为当前故事已经固定玩家为十五岁、将在本学年满十六岁，不额外要求玩家输入出生年份。

## V4：分院仪式第二节

姓名之后进入新生分院仪式。

流程：

1. 先显示分院礼堂正文。
2. 点继续。
3. 下一页选择四组学院品质。
4. 选择后，后台确定主控所属学院并自动切换学院主题色。
5. 下一页显示对应学院宣言。
6. 格兰芬多可继续进入现有 Lisa / Nate 主线；其余学院暂时显示“正在续写中...”。

四组品质和学院对应关系已经写入代码，但页面不会提前把学院名直接写在选项上。


## V5：斯莱特林进入 Nate 线

斯莱特林宣言之后不再直接显示“正在续写中”，现在会进入一段独立的斯莱特林视角剧情：

- 主控因为学院环境，对 Nate / Lisa 的名气、实力、血统与校园位置比其他学院更有意识。
- 通过斯莱特林毕业生 Susanna Kaysen 教授的课真正注意到两人。
- 一次课后主控留下问问题，Nate / Lisa 同时在场。
- Susanna 与主控围绕一个给分点进行即时问答。
- Nate 在主控疏忽时轻轻戳手心提醒。
- 主控随后可以用三种方式道谢并顺势拉近距离：
  - 霍格莫德：Nate +15
  - 图书馆：Nate +20
  - 假期来家里：Nate +20
- 三种方式都会让 Lisa 因为主控的斯莱特林身份与主动接近 Nate 的方式而多留意主控：Lisa +10。
- 好感变化仍然完全隐藏，不会显示在选项下面。
- 当前没有把“斯莱特林 = 纯血”写死；血统仍等待后续剧情决定。

# LisaNateHogwarts01 — V3 开场测试版

这版完全保留 V2 已经确认过的 UI 框架，只改开场流程与玩家资料。

## 新开场流程

1. 显示用户提供的九月 / 九又四分之三站台 / 列车开场文字。
2. 文字结束后进入生日填写页。
3. 玩家填写生日（月 / 日）。
4. 进入姓名填写页，填写“名”和“姓”。
5. 后续剧情可以直接写 `【玩家名字】`，游戏会自动替换成玩家输入的姓名。
6. 正文中用 `*文字*` 包起来，可以显示斜体。
7. 进入原本的分院流程。

## 这版新增的正文写法

### 自动插入玩家姓名

直接写：

```js
"十五岁的【玩家名字】，你好。"
```

玩家如果填写 Jane Doe，游戏里就会显示：

```text
十五岁的 Jane Doe，你好。
```

### 斜体

直接写：

```js
"也许会有*期待中的邂逅*。"
```

星号里的部分会自动显示为斜体。

## 玩家资料

角色状态面板现在会记录并显示：

- 姓名
- 生日
- 学院
- 血统背景

当前流程：

1. 斯莱特林主控对 Nate / Lisa 已有名气、实力、血统层面的耳闻。
2. 进入 Susanna Kaysen 教授的课程。
3. 课后主控留下问问题，Nate / Lisa 也在场。
4. 主控与 Susanna 争论一个得分点。
5. Susanna 给出“现在全答对就算满分”的机会。
6. Nate 在主控疏忽时悄悄戳手心提醒。
7. 主控向 Nate 道谢，并选择三种拉近距离的方式：
   - 霍格莫德：Nate +15
   - 图书馆自习：Nate +20

页面仍然不会直接显示好感度加分。

## V8：六档存读档系统

新增一个尽量简洁的乙女游戏式菜单。

右上角“菜单”中包含：
- 当前玩家状态
- 回到开头
- 6 个手动存档位
- 每个档位可存档 / 覆盖 / 读档 / 删除

### 自动续玩

游戏每次进入新场景都会自动把当前 `state + sceneId` 写入浏览器 `localStorage`。

因此：
- 普通刷新不会再回到开头；
- 关闭网页后重新打开，也会回到最近停留的页面；
- “回到开头”只清除自动进度，不删除六个手动存档。

### 手动存档

每个档位保存：
- 当前场景
- 姓名
- 生日
- 学院
- 血统
- 好感度
- 历史最高好感
- 所有剧情选择 / flags
- 玩家在 Susanna 场景输入的自由台词
- 当前 UI 主题状态

存档存于当前浏览器的 localStorage；如果换浏览器、换设备或清理网站数据，存档不会自动同步过去。


## V9：拉文克劳初遇路线

新增拉文克劳路线。

### 前情数值
进入拉文克劳路线时，Nate 对玩家已有基础好感 `30`。
这个基础值通过 `ravenclawStartingBondApplied` 确保只加一次。

### 破冰选择
四种选择都会让 Nate `+30`：
- 冷酷回答
- 表示旧友谊毫无影响
- 主动约黑湖散步
- 不回答、转头和别人说话

Lisa 在这一段不加分。

### 后续分流
- 冷酷回答 / 表示毫无影响：
  Nate 先“oh”并退回去做自己的事，课后主动约霍格莫德。
- 不回答：
  Nate 课后仍主动尝试破冰并约霍格莫德。
- 主动约黑湖：
  Nate 罕见地灿烂笑并答应，直接提出周日先散步、再找 Lisa、再三人去霍格莫德。

### 霍格莫德追问
对于 Nate 主动发出的邀约，玩家可选：
- “就我们俩？”
- “那个谁不会也……”

随后 Nate 说明 Lisa 也会一起。

拉文克劳路线的“双生镜像”“曾经可能成为挚友”“三人关系对拉文克劳主控意义更深”“以后双人加分可以更高”等，目前作为剧情结构保留，未擅自新增额外数值。

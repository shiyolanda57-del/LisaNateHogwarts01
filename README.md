# LisaNateHogwarts01 — V3 开场测试版

这版完全保留 V2 已经确认过的 UI 框架，只改开场流程与玩家资料。

## 新开场流程

1. 显示用户提供的九月 / 九又四分之三站台 / 列车开场文字。
2. 文字结束后进入生日填写页。
3. 玩家填写生日（月 / 日）。
4. 进入姓名填写页，填写“名”和“姓”。
5. 后续剧情可以直接写 `【玩家名字】`，游戏会自动替换成玩家输入的姓名。
6. 正文中用 `*文字*` 包起来，可以显示斜体。
7. 进入原本的分院流程。

## 这版新增的正文写法

### 自动插入玩家姓名

直接写：

```js
"十五岁的【玩家名字】，你好。"
```

玩家如果填写 Jane Doe，游戏里就会显示：

```text
十五岁的 Jane Doe，你好。
```

### 斜体

直接写：

```js
"也许会有*期待中的邂逅*。"
```

星号里的部分会自动显示为斜体。

## 玩家资料

角色状态面板现在会记录并显示：

- 姓名
- 生日
- 学院
- 血统背景
- Lisa 好感度
- Nate 好感度

生日目前只填写“月 / 日”，因为当前故事已经固定玩家为十五岁、将在本学年满十六岁，不额外要求玩家输入出生年份。

## V4：分院仪式第二节

姓名之后进入新生分院仪式。

流程：

1. 先显示分院礼堂正文。
2. 点继续。
3. 下一页选择四组学院品质。
4. 选择后，后台确定主控所属学院并自动切换学院主题色。
5. 下一页显示对应学院宣言。
6. 格兰芬多可继续进入现有 Lisa / Nate 主线；其余学院暂时显示“正在续写中...”。

四组品质和学院对应关系已经写入代码，但页面不会提前把学院名直接写在选项上。


## V5：斯莱特林初遇分支

分院后，斯莱特林不再直接显示“正在续写中”，而是进入自己的初遇路线。

当前流程：

1. 斯莱特林主控对 Nate / Lisa 已有名气、实力、血统层面的耳闻。
2. 进入 Susanna Kaysen 教授的课程。
3. 课后主控留下问问题，Nate / Lisa 也在场。
4. 主控与 Susanna 争论一个得分点。
5. Susanna 给出“现在全答对就算满分”的机会。
6. Nate 在主控疏忽时悄悄戳手心提醒。
7. 主控向 Nate 道谢，并选择三种拉近距离的方式：
   - 霍格莫德：Nate +15
   - 图书馆自习：Nate +20
   - 假期来家里玩：Nate +20
8. 三个选项都会同时让 Lisa +10。
9. 当前斯莱特林路线到此结束，后续继续留“正在续写中”。

页面仍然不会直接显示好感度加分。


## V5.1 修正：学院选择后的跳转

学院分流已改成“每个学院直接跳到自己的宣言场景”，不再共用一个依赖当前状态动态判断的宣言页面。

这样避免了选择学院之后出现按钮无响应或跳转状态不一致的问题。

已对四个学院做自动路由测试：
- 格兰芬多 → 格兰芬多宣言 → 格兰芬多剧情
- 斯莱特林 → 斯莱特林宣言 → 斯莱特林剧情
- 拉文克劳 → 拉文克劳宣言 → 正在续写中
- 赫奇帕奇 → 赫奇帕奇宣言 → 正在续写中

# LisaNateHogwarts01 — V2

这一版针对“游玩体验”做了结构调整。

## V2 已改动

- 初始页面改成简单黑白主题。
- 玩家选择学院后，自动进入对应学院主题色。
- 选择学院后，右上角出现“回到初始配色”按钮。
- 回到黑白后，可再点“恢复学院配色”。
- 开场改成讲故事流程：
  1. 开场文字
  2. 询问名字
  3. 玩家填写“名”和“姓”
  4. 承接故事
  5. 进入分院
  6. 进入 Lisa / Nate 初遇剧情
- 姓名、学院、血统、好感度不再常驻显示。
- 右上角“角色状态”按钮可随时点开查看。
- 选项下不再显示“Lisa +30 / Nate +20”等好感变化。
- 仅保留必要的身份锁定提示，例如：
  “选择此选项后，本局游戏将以纯血家族巫师背景游玩。”
- 原有 Lisa / Nate 分支、好感计算、峰值记录、结局判定仍保留。
- 没有补写你没给出的剧情，所有空缺继续使用“仍需填入……”占位。

## 上传到 GitHub

用 V2 的三个核心文件覆盖仓库中的旧文件：

- `index.html`
- `style.css`
- `game.js`

`README.md` 可一起覆盖，也可以不上传。

GitHub Pages 会在 Commit 后自动重新部署，原来的游戏网址不变。

## 之后填正文

剧情仍然主要在 `game.js` 的 `scenes` 中。

例如：

```js
paragraphs: () => [
  "仍需填入游戏开场文字。",
]
```

把引号中的占位文字换成你的文字即可。

## 注意

好感度仍然在后台正常计算，只是不直接提示玩家。

如果未来你决定“角色状态界面也不应该精确显示数字，只显示模糊状态”，也可以继续改成：

- 陌生
- 留意
- 熟悉
- 亲近
- 不可割舍

之类的文字层级；当前版本仍按照你的要求，在主动点开的状态页中显示实际好感数值。
